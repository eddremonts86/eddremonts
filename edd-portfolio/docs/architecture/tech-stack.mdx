## Decisiones de arquitectura

### ¿Por qué React 19 + Vite (no Next.js)?

- **SPA estática**: No necesitamos SSR, API routes ni file-system routing
- **Simpleza**: Una sola página, cero complejidad de routing
- **Performance**: Vite ofrece HMR ultra-rápido y bundling optimizado con Rollup
- **Deploy**: Bundle estático en Netlify — sin serverless functions necesarias

### ¿Por qué Tailwind CSS?

- Design tokens como clases utilitarias (`bg-background`, `text-primary`)
- Tematización light/dark via CSS custom properties + clase `.dark`
- Plugin de Prettier ordena clases automáticamente
- Purging automático → CSS final mínimo

### ¿Por qué Framer Motion?

- Animaciones basadas en física (springs) para interacciones naturales
- `useScroll` + `useTransform` para parallax scroll-linked
- `AnimatePresence` para transiciones de entrada/salida
- `useReducedMotion()` para respetar preferencias de accesibilidad
- API declarativa compatible con React 19

### ¿Por qué i18next?

- Detección automática del idioma del navegador
- Persistencia en `localStorage`
- Interpolación y objetos anidados en traducciones
- `returnObjects: true` permite arrays complejos (testimonios)

### ¿Por qué Formspree?

- No requiere backend propio
- Protección anti-spam incluida
- Validación server-side
- Free tier suficiente para un portfolio
