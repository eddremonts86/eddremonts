# Edd Portfolio — Developer Documentation

> Portfolio personal de **Edd Remonts** — Senior Full-Stack/Frontend Engineer, Copenhagen, Denmark.
>
> **Live:** [eddremonts.dk](https://eddremonts.dk) · **Stack:** React 19 + TypeScript + Tailwind CSS + Framer Motion + Vite 7

---

## Quick Start

```bash
pnpm install
pnpm dev        # http://localhost:5173
```

Consulta [Getting Started → Installation](getting-started/installation.mdx) para los requisitos completos.
