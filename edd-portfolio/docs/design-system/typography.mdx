## Familias tipográficas

| Familia | Variable CSS | Clase Tailwind | Uso |
|---------|-------------|---------------|-----|
| **M PLUS 1 Variable** | `font-display` | `font-display` | Headlines, títulos de impacto |
| **Epilogue** | `font-body` | `font-body` | Texto de cuerpo, descripciones |
| **Cinzel** | `font-serif` | `font-serif` | Acentos serif decorativos |
| **JetBrains Mono** | `font-mono` | `font-mono` | Código, etiquetas mono |

> Las fuentes se cargan via `@fontsource-variable` (self-hosted, sin requests externos a Google Fonts).

## Escala tipográfica

### Hero (heading principal)

```tsx
<h1 className="font-display text-6xl md:text-8xl lg:text-[10rem] font-bold tracking-tight">
  EDO REMONTS
</h1>
```

### Section headings

```tsx
<h2 className="font-display text-4xl md:text-5xl lg:text-6xl font-bold">
  Section Title
</h2>
```

### Subtítulos

```tsx
<p className="font-body text-lg md:text-xl text-secondary">
  Section description text
</p>
```

### Body text

```tsx
<p className="font-body text-base text-foreground/80">
  Regular paragraph text
</p>
```

### Code / Mono

```tsx
<code className="font-mono text-sm">
  const greeting = "Hello";
</code>
```

### Badges / Labels

```tsx
<span className="font-mono text-xs uppercase tracking-wider">
  LABEL TEXT
</span>
```

## Configuración en Tailwind

```js
// tailwind.config.js
theme: {
  extend: {
    fontFamily: {
      display: ['M PLUS 1 Variable', ...defaultTheme.fontFamily.sans],
      body: ['Epilogue', ...defaultTheme.fontFamily.sans],
      serif: ['Cinzel', ...defaultTheme.fontFamily.serif],
      mono: ['JetBrains Mono', ...defaultTheme.fontFamily.mono],
    }
  }
}
```

## Principios de diseño tipográfico

1. **Contraste extremo**: El hero usa tipografía gigante (10rem) contra espacios vacíos amplios
2. **Jerarquía clara**: `font-display` para títulos, `font-body` para lectura, `font-mono` para labels técnicos
3. **Tracking tight en headings**: `tracking-tight` (-0.025em) para compactar letras en títulos
4. **Tracking wide en labels**: `tracking-wider` (0.05em) para labels uppercase mono
5. **Opacidad para jerarquía**: `text-foreground/80`, `text-foreground/60` para niveles secundarios
