# Components Index

Mapa completo de todos los componentes del proyecto organizados por sección.

---

## Secciones de la página

Cada sección ocupa un viewport completo y se renderiza como un bloque de scroll vertical en `App.tsx`.

| # | Sección | Carpeta | Componente principal | Import |
|---|---------|---------|---------------------|--------|
| 1 | Hero | `hero/` | `HeroSection` | ⚡ Eager |
| 2 | Stats | `stats/` | `StatsCounter` | ⚡ Eager |
| 3 | About | `about/` | `AboutSection` | ⚡ Eager |
| 4 | Skills | `skills/` | `SkillsMarquee` | ⚡ Eager |
| 5 | Experience | `experience/` | `ExperienceTimeline` | ⚡ Eager |
| 6 | Testimonials | `testimonials/` | `TestimonialBlock` | ⚡ Eager |
| 7 | Projects | `projects/` | `ProjectsGallery` | 💤 Lazy |
| 8 | Code | `code/` | `CodeShowcase` | 💤 Lazy |
| 9 | Contact | `contact/` | `ContactSection` | 💤 Lazy |
| — | Footer | `footer/` | `Footer` | ⚡ Eager |

---

## UI Primitives

Componentes reutilizables compartidos entre múltiples secciones:

| Subcarpeta | Componentes | Función |
|-----------|------------|---------|
| `ui/badges/` | `StatusBadge`, `TechBadge`, `ContactInfoItem` | Etiquetas, pills, items de info |
| `ui/layout/` | `Preloader`, `MouseFollower`, `SEO` | Layout global y meta |
| `ui/media/` | `OptimizedImage`, `IconComponent` | Imágenes y iconos |
| `ui/navigation/` | `StickyNav`, `DotNavigation`, `LanguageSelector`, `ThemeToggle` | Navegación global |
